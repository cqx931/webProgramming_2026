#### VS Code Set up
1. The file `.vscode/extensions.json` will ask you to install recommended extensions for this class the first time you open this folder. Please follow the instructions and install.

2. The settings in `.vscode/settings.json` apply **automatically** when you open this folder in VS Code.

    - If you already had the folder open: press `Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Windows), type **Reload Window**, press Enter.
    - Want the same settings in another folder? You can copy the file `.vscode/settings.json` over.
    - Want the same settings in all your projects? Press `Cmd/Ctrl+Shift+P` → **Preferences: Open User Settings (JSON)**, then copy the contents of `.vscode/settings.json` into the `{ }` of that file.

    What these settings do:
    - Disable Chat Assistant
    - Turn off AI autocomplete (GitHub Copilot / inline suggestions) — write the code yourself!
    - Make sure to turn on Emmet: type `!` + `Tab` for a full HTML skeleton, `ul>li*3` + `Tab` expands into a nested list.
