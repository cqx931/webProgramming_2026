### VS Code Setup

The settings in `.vscode/settings.json` apply **automatically** when you open this folder in VS Code.

- If you already had the folder open: press `Cmd+Shift+P` (Mac) / `Ctrl+Shift+P` (Windows), type **Reload Window**, press Enter.
- Want the same settings in all your projects? Press `Cmd/Ctrl+Shift+P` → **Preferences: Open User Settings (JSON)**, then copy the contents of `.vscode/settings.json` into the `{ }` of that file.

What these settings do:

- Turn off AI autocomplete (GitHub Copilot / inline suggestions) — write the code yourself!
- Turn on Emmet: type `!` + `Tab` for a full HTML skeleton, `ul>li*3` + `Tab` expands into a nested list.
