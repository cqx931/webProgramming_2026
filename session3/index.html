Flow Layout: The Default

By default, elements are laid out following the normal flow of the document. Block-level elements stack vertically, while inline elements flow horizontally within their containing block. This default behavior can be overridden by CSS properties like display, position, float to create more complicated layouts.

Position

We use position to take an element out of the normal flow of a document. It has various positioning schemes to control how elements are placed on the page.

  • static: The default flow of the document.
  • relative: Positioned relative to its normal position. Ex: absolute parent
  • absolute: Positioned relative to the nearest positioned ancestor.
  • fixed: Positioned relative to the viewport, stays in place during scrolling. Ex: pop-up windows
  • sticky: Toggles between relative and fixed based on scroll position.

It overrides not only the normal flow, but also other general layout frameworks such as Flexbox or Grid. In this way we can design the general layout of a page using Flexbox, but it is still possible to change the position property for a specific element inside this layout.

Position: relative

An element with position: relative; is positioned relative to its normal position in the document flow. Settings like the top, right, bottom and left properties will cause the element to be adjusted away from its normal position. These properties only work on positioned elements (elements with position set to relative, absolute, fixed, or sticky). 

/* Static: default flow */
.element {
    position: static;
    top:10px; /* has no effect */
    left:20px; /* has no effect */
}       
/* Relative: offset from normal position */
#relative {
    position: relative;
    top: 10px; /* moves down 10px */
    left: 20px; /* moves right 20px */
}

Position: absolute

An element with position: absolute; is positioned relative to the nearest ancestor with a set position (any position other than static). However, if an absolute positioned element has no positioned ancestors, it uses the document body, and moves along with page scrolling.

Most of the time we use it together with position: relative; for the reference div in relation to an element by itself while keeping the parent element in the normal flow.

Absolute positioning removes the element from the normal document flow, so it does not affect the position of other elements. Notice that its parent is also not affected by it at all. 

/* Absolute: positioned relative to nearest positioned ancestor */
div.relative {
  position: relative;
  width: 400px;
  height: 200px; # if we remove the height from parent div, the parent doesn't adjust its height to the absolute child div 
  padding: 5px;
  border: 3px solid green;
}

div.absolute {
  position: absolute;
  top: 80px;
  right: 5px;
  width: 200px;
  height: 100px;
  padding: 5px;
  border: 3px solid red;
}

Position: fixed

An element with position: fixed; is positioned relative to the viewport, which means it always stays in the same place even if the page is scrolled. Fixed positioning removes the element from the normal document flow, so it does not affect the position of other elements and other elements will not affect its position.

/* Fixed: positioned relative to the viewport */
div.fixed {
  position: fixed;
  background:#eee; 
  top: 500px;
  left: 10px;
  width: 150px;
  height: 50px;
  padding: 5px;
  border: 3px solid blue;
}
This div element has position: fixed

Position: sticky

position: sticky; is relatively new to positions (does not work for very old browsers) and it has a cute sticky effect. It behaves like relative until it reaches a defined scroll position, then it becomes fixed until it is out of the viewport. 

/* Sticky: toggles between relative and fixed based on scroll position */
div.sticky {
    position: sticky;
    top: 0; /* Sticks to the top of the viewport when you reach its scroll position */      
    background: #f39c12;
    padding: 5px;
    border: 3px solid orange;
}

Z-Index

Once we start to take elements out of the normal flow, there is a chance that they might overlap with each other. The z-index property comes in handy when that happens. Elements with a higher z-index will appear in front of elements with a lower z-index.
If two positioned elements overlap without a z-index specified, the element positioned last in the HTML code will be shown on top. 

/* Z-Index: controls stacking order */
div.z-index-demo {
    position: absolute; /* z-index only works on positioned elements */
    z-index: 1; /* default value is auto */
    opacity: 0.8; /* for better visibility of overlapping elements */
    width:200px;
    height:150px;
    color:white;
    padding:5px;
    margin:40px;
    left:0;
    top:0;
}

div.z-index-demo.front { 
    z-index: 2; /* overrides z-index of 1 */
    left:40px;
    top:40px;
} /* appears in front */

div.z-index-demo.back { 
    z-index: 0; /*  overrides z-index of 1 */
    left:-40px;
    top:-40px;
} /* appears behind */
Red (z-index: 2)
Blue (z-index: 1)
Yellow (z-index: 0)

This is very useful when you want to put an image as a partial background of a div and put some text on top of it. You can set the image div to have a lower z-index than the text div, so the text will be visible on top of the image.

.image {
    position: absolute;
    z-index: 0;
    width: 100%;
    height: 100%;
    background-image: url('https://upload.wikimedia.org/wikipedia/commons/thumb/0/0a/Leuphana_Building.jpg/960px-Leuphana_Building.jpg');
    background-size: cover;
    background-position: center;
}       
.text {
    position: relative;
    z-index: 1;
    color: black;
    padding: 20px;
}

Z-index also takes negative values, which can be useful when you want to place an element behind the normal flow of the document (everything else). For example, you can use a negative z-index to create a background image that sits behind all other content on the page. However, be cautious when using negative z-index values, as they can make elements difficult to interact with.

If you want to create complicated layered effects or ensure that certain elements always appear above or below others without needing to manage z-index values across the entire document, you can use the isolation property. We can set this property to isolate, which creates a new stacking context for the element and its children. 

/* Isolation: creates a new stacking context */
.isolated {
    isolation: isolate; # if we remove this line, the red div will disappear because it is behind the normal flow of the document
    position: relative; 
    background-color:#f0ede6;
}
#blue-div {
    position:absolute; 
    background-color:var(--mondrian-blue); 
}
#red-div {
    position:absolute; 
    background-color:var(--mondrian-red); 
    z-index:-1;
}

Float

The float property is used to wrap text around images or to create multi-column layouts. It can be a bit tricky to work with, especially when it comes to clearing floats and understanding how it interacts with the document flow.

/* Float: allows elements to float to the left or right */
img {
    float: left; /* or right */
    margin: 0 1rem 1rem 0; /* add some spacing */
}

Simple Float Layout

Once we have float, we can use it to create more complex layouts. For example, we can create a two-column layout with a sidebar and main content area by letting them float side by side. This is how websites were built before the introduction of more modern layout techniques like Flexbox and Grid. For more complex layouts, one usually uses a multi-column boilerplate that is based on floats.

Flexbox

CSS Flexbox is a one-dimensional layout system that allows you to arrange items either in rows or in columns. It is particularly useful for creating flexible and responsive layouts, as it can easily adjust the size and position of items based on the available space. → Check out the Flexbox Layout

A flexbox always consists of:

  • A Flex Container - The parent (container) element, where the display property is set to flex or inline-flex
  • One or more Flex Items - The direct children of the flex container automatically become flex items

Here is a simple example: 

/* Simple flexbox layout */
.flex-container {
    display: flex; /* turns the container into a flex container */
    justify-content: space-between; /* distributes items along the main axis */
    gap: 1rem; /* spacing between items */
}
.flex-item {
    padding: 1rem;
    text-align: center;
}

Grid

CSS Grid is a 2D layout system that allows you to create complex, responsive grid-based layouts with ease. It enables you to control both rows and columns simultaneously. It is a very powerful layout system that takes a bit of time to learn. Due to the limited sessions of this class, we won't be able to learn it in detail here. However, I highly recommend you to check it out after you are familiar with the Flexbox system and other CSS concepts.

Here is a simple grid example just to show what it's capable of doing. 

/* Simple grid layout: control columns AND rows */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* three columns of equal width */
    grid-template-rows: repeat(3, 100px); /* three rows of fixed height */
    gap: 1rem; /* spacing between cells */
}
.grid-item {
    padding: 1rem;
    text-align: center;
}
/* items can span multiple columns or rows */
.item-1, .item-5 {
    grid-column: span 2; /* take up two columns */
}
.item-2 {
    grid-row: span 2; /* take up two rows */
}

Unlike Flexbox, which works along one axis (a row or a column), Grid lets you control rows and columns at the same time, which makes it a great choice for building entire page layouts.

How to Center a Div

Centering a div can be achieved using different CSS layout techniques depending on the context.

1. Margin Auto:

/* Centering with margin auto */
.centered {
    width: 200px; /* set a fixed width */
    margin: 0 auto; /* auto left and right margins */
    /* Vertical centering without using grid or flexbox is more complex and often requires additional techniques, such as using display: table or absolute positioning. */
}
Centered with Margin Auto

2. Flexbox:

/* Centering with Flexbox */
.container_flex {
    display: flex;
    justify-content: center; /* horizontal centering */
    align-items: center; /* vertical centering */
}
Centered with Flexbox

3. Grid:

/* Centering with Grid */
.container_grid {
    display: grid;
    place-items: center; /* centers both horizontally and vertically */
}
Centered with Grid

Display Images

One common issue one needs to solve is when multiple images don't share the same format but we still want them to look nice together. There are a few CSS rules that can help you with that.

object-fit

The object-fit property controls how an image (or video) is resized to fit into its box. It only works when the element has both a width and a height set. By default, the image is stretched to fill the box (fill), which ignores the image's aspect ratio and can look distorted. With the right value, we can make images with different formats look nice together.

  • fill (default): stretches the image to fill the box, ignoring its aspect ratio (the image may look distorted).
  • contain: scales the image so it fits entirely inside the box, leaving empty space around it if the aspect ratios don't match.
  • cover: scales the image so it fills the box completely, cropping the overflow. The most useful value to make images look uniform.
  • none: no scaling, the image keeps its natural size and may overflow the box.
  • scale-down: behaves like none or contain, whichever results in a smaller image.
/* Object-fit: how the image fits into its box */
img {
    width: 160px;
    height: 120px;
    object-fit: cover; /* fill | contain | cover | none | scale-down */
}

Note: object-fit only works on replaced elements such as <img> and <video>. For background images, use background-size instead (see below).

object-position

The object-position property controls which part of the image is visible inside the box. It is most useful together with object-fit: cover;, when part of the image gets cropped. The default value is center.

/* Object-position: which part of the image is visible */
img {
    width: 160px;
    height: 120px;
    object-fit: cover;
    object-position: left; /* keywords: left/center/right + top/center/bottom, or percentages: x% y% */
}

In the demo above, the image overflows horizontally, so the horizontal keywords (left, center, right) change the result. If your image overflows vertically (e.g. a portrait image in a landscape box), the vertical keywords (top, center, bottom) come into play. You can combine both axes, e.g. object-position: left top;, or use percentages like 20% 80%.

Background Images

The background-image property allows you to set an image as the background of an element. You can use the url() function to specify the path to the image. You can set the background image to cover the entire element, position it, and control whether it repeats or not using properties like background-size, background-position, and background-repeat. Detailed information about background properties can be found here. 

/* Set a background image */
div {
    background-color:rgba(255,255,255,0.8); /* Optional: add a semi-transparent overlay */
    background-image: url('https://upload.wikimedia.org/wikipedia/commons/thumb/0/0a/Leuphana_Building.jpg/960px-Leuphana_Building.jpg');
    background-size: cover; /* Make the image cover the entire element */
    background-position: center; /* Center the image */
    background-repeat: no-repeat; /* Prevent tiling */
}

Gradient Backgrounds

CSS gradients allow you to create smooth transitions between two or more colors.

/* Gradient Backgrounds */
div.linear-gradient {
    background: linear-gradient(to right, #e74c3c, #3498db); /* Linear gradient from red to blue */
}
div.radial-gradient {
    background: radial-gradient(circle, #2ecc71, #27ae60); /* Radial gradient from light green to dark green */
}

The background property is a powerful shorthand that can set multiple background-related properties at once.

/* Shorthand for multiple background properties */
background: url('image.jpg') no-repeat center/cover;
background: linear-gradient(to right, #e74c3c, #3498db);
